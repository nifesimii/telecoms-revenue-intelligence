## Question

Using the agreed dealer stories, what review journey makes the financial
statements, health observations and supporting evidence understandable to
Finance? Create a throwaway prototype for user feedback and decide whether this
belongs in a new workspace or an existing dealer view. Cover the selected
reporting periods, source freshness, synthetic-data labels, and missing or stale
evidence. Link the prototype as an asset; record the user's response before
resolving. The prototype is a planning aid, not the production feature.
